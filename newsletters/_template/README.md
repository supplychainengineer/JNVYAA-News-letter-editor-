Copy this folder to start a new issue, e.g. `newsletters/2026-12/`.

- Put your text in `content.md` (or `content.csv` / `content.json` / plain `content.txt`).
- Put photos in `photos/` (or loose next to the content file).
- Push to `main` — the GitHub Action builds `issues/<folder>/` with HTML, PDF and PNG.

Folders starting with `_` are skipped.
